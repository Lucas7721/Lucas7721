## Sobre mim

Sou desenvolvedor com base forte em Python e experiência prática em automação, web scraping, processamento de dados, OCR, IA e visão computacional.

Tenho domínio em desenvolvimento de ferramentas internas, automações, pipelines de mídia, coleta de dados, integrações com APIs e soluções orientadas a produtividade.

Também venho ampliando bastante meu repertório em frontend e desktop apps com React, TypeScript, Tailwind e Electron quando o produto pede interface mais polida.

## Especialidades

- automações de navegador e web scraping com Selenium, Playwright, Patchright e Camoufox
- projetos de IA com PyTorch, YOLO, OpenCV e OCR
- ferramentas para processamento de vídeo, áudio, imagem e texto
- apps web e desktop com React, TypeScript, Vite e Electron
- integrações com bancos de dados relacionais e NoSQL
